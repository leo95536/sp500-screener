# S&P500 사이클 스크리너

"테슬라 가격 패턴" 종목 발굴: 장기 우상향 골격 위에서 급락–회복 사이클을
반복하는 종목이 급락 국면에 들어왔을 때 포착한다.

**대시보드**: https://leo95536.github.io/sp500-screener/

## 스크리닝 조건 (v3)

1. **시장의 지속적 관심** — 분기(63거래일) 이동평균 거래대금(종가×거래량)이
   최근 2년 내내 $500M 이상
2. **사이클 이력** — 최근 10년 동안 "낙폭 -25% 초과 → 전고점 완전 회복" 2회 이상
   완주하고 최근 5년 총수익률 > 0 (나락형 제외, 사이클형만)
3. **현재 국면** — 랠리(고점이 그 시점 1년 전 대비 +30% 이상)로 만든 최근 2년 내
   고점에서 -25% 이상 하락 중

모든 기준값은 [screener.py](screener.py)의 `CONFIG`에서 수정.

## 동작

- GitHub Actions가 평일 UTC 22:00(한국 아침 7시)에 [screener.py](screener.py)를 실행해
  `data.json`을 갱신하고, GitHub Pages(main/root)가 대시보드를 서빙한다.
- 데이터: Yahoo Finance (yfinance), 배당·분할 반영 수정종가.
- 로컬 실행: `pip install -r requirements.txt && python screener.py`
